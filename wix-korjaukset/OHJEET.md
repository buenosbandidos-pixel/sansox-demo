# Wix-pikakorjaukset — klikkausohjeet (yht. ~1,5 h)
Tekijä: kuka tahansa jolla Wix-ylläpitotunnus. Järjestys tärkeimmästä alkaen.

## 1. LinkedIn-linkki (2 min) 🔴
Wix-editori → etusivu → Social Bar -elementti → klikkaa → "Set Social Links"
→ LinkedIn-rivillä URL on nyt linkedin.com/company/wix-com → vaihda SansOxin omaan.
⚠️ Jos yrityssivua ei ole: linkedin.com/company/setup/new → luo "SansOx Oy" (15 min) → sitten URL tänne.

## 2. Blogin tekoälykansikuva pois (10 min) 🔴
Wix → Blog → postaus "Pharmaseutical residues" (11.3.2026) → Edit
→ vaihda kansikuva (nykyinen: lasi+ketju-kuvituskuva) → lataa tästä paketista:
   kansikuvat/blogi_kansikuva_A_koekuva.jpg  (suositus: aito koekuva julkaisusta)
   TAI kansikuvat/blogi_kansikuva_B_asennus.jpg
→ Update. Sama tarkistus postaukselle jossa sama kuva toistuu.

## 3. YouTube-kanavan nimi (5 min) 🟠 — tekijä: Jukka
studio.youtube.com → Customization → Basic info → Name: "SansOx Oy"
(Videot ja tilaajat säilyvät. Oikea brändikanava voidaan tehdä myöhemmin rauhassa.)

## 4. Store-hinnat piiloon (30–60 min) 🟠
Wix → Stores → Settings → (a) piilota hinta tuotesivuilta TAI (b) "Request a quote" -tila
→ tarkista että "0 EUR / 1 EUR" ja ostoskori katoavat tuotesivuilta ja Solutions-listauksesta.

## 5. Lukustrip etusivulle (30 min) 🟡
Wix-editori → etusivu → Add Section → Strip → 4 saraketta
→ tekstit tiedostosta lukustrip_tekstit.txt sellaisenaan.
⚠️ Kohdat 4–5 ovat välikorjauksia: turhia, jos uusi sivusto julkaistaan lokakuussa.
